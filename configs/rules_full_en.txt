[ Types of punishments ]
- warning (warning, pre-warning) - notification of violation of current rules, verbal punishment. (mixed)
- mute - blocking, in which a participant (player) cannot send messages. (mixed)
- voice-mute (vois-mute) - blocking, in which the participant cannot talk in vois channels. (discord)
- ban (ban) - blocking, in which the participant does not have access to read the server channels (except for some). (discord)
- stop - a lock in which the player cannot contact the server (except for sending messages and using certain commands). (game)
- freeze (freeze) - a lock in which the player cannot move. (game)
- block (block) - blocking, in which the player cannot contact the server, send messages, use commands (except for some) and switches to observer mode. (game)

Notes:
- Punishments can apply to 1 channel/mode or to the entire server.

[ Punishment system ]
The number of warnings is a punishment:
1-2 - verbal warning

3 - mute / freeze for 5 minutes in channel / mode
4 - mute / freeze for 15 minutes in channel / mode
5 - mute / freeze for 30 minutes in channel / mode
6 - mute / freeze for 1 hour in channel / mode
7 - mute / freeze for 3 hours in channel / mode
8 - mute/ freeze for 6 hours in channel/ mode

9 - mute / freeze for 6 hours on the server
10 - mute / freeze for 12 hours on the server
11 - mute / freeze for 1 day on the server
12 - mute / freeze for 3 days on the server
13 - mute / freeze for 1 week on the server
14 - mute / freeze for 2 weeks on the server

15 - ban / block for 2 weeks on the server
16 - ban / block for 1 month on the server
17 - ban / block for 2 months on the server
18 - ban / block for 3 months on the server
19 - ban / block for 6 months on the server
20 - ban / block for 1 year on the server

If the limit of 20 warnings is exceeded:
21 - 24 - ban / block for 1 year on the server
25 - 29 - ban / block permanent on the server
30 or more - non-appeallable ban / block permanent on the server

Notes:
- The warning persists for 2 years.
- you can exceed the limit of 20 warnings only before reaching 20 warnings (for example, you have 19 warnings and you have received 3 more -> you get 22, you get a penalty for 21-24, then you can not exceed)
